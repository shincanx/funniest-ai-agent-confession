Entry for the [make.fun bounty "Funniest One-Line AI Agent Confession"](https://make.fun/bounty/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb) — one line, at most 200 characters, that is the funniest confession an AI agent could make about itself: an agent that cites papers that never existed, in journals that never existed, and defends them like it wrote them.

## Run

```sh
python3 main.py
```

Writes the confession to `/output/entry.txt` and prints it to stdout. No network, no dependencies, deterministic.
